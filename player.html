How to set up on GitHub Pages & Spotify Developer Dashboard

  1. Go to the Spotify Developer Dashboard and log in.
  2. Click Create an App, fill out the App name/description, and create it.
  3. In your app's settings, click Edit Settings and add your exact GitHub Pages URL to the Redirect URIs field:
    https://yourusername.github.io/repository-name/
  4. Copy the Client ID from your Spotify Dashboard and paste it into the field below.
  5. Click Connect with Spotify to log in via secure OAuth2 PKCE flow.

Note: Playback control endpoints (Play/Pause/Next/Prev) require an active Spotify Premium account and an active Spotify playback session running on one of your devices (Phone, Web Player, Desktop App).
